# Harnessform deployment

Harnessform is the Australia + France harness-racing companion to Classform.

## Streamlit Community Cloud

Create a new app from the existing repository:

- Repository: `sbachagian1101/Classform`
- Branch: `main`
- Main file path: `harness_app.py`
- Suggested app URL: `harnessformsuraj.streamlit.app`

Do not change the existing Classform (`app.py`) or Greyform (`greyhound_app.py`) deployments.

## Workflow

1. Copy the complete Racing & Sports harness race page.
2. Paste it into Harnessform (or upload `.txt` / `.md`).
3. Choose Market / odds weight from 0–40% (default 35%).
4. Press **Parse & Predict**.
5. Review Final, Form and Market rankings.
6. Open **Why ...?** for factor scores and **Full form history** for parsed starts.

The parser supports both full R&S markdown and normal browser-copy plain text for Australian and French harness races.
