CLASS-ONLY RACE ANALYSER v4-mobile
==================================

This package can be used in two ways:

1) MOBILE / WEB
   Upload the package contents to GitHub and deploy app.py on Streamlit Community Cloud.
   See DEPLOY_GITHUB_STREAMLIT.md.

2) WINDOWS LOCAL
   Double-click run.bat.

The model remains the supplied v4 France + Australia class-only model.
The mobile conversion changes the user interface/deployment packaging only.
